Formulation

The math behind every decision

Every quantity the simulation displays — risk scores, the stress gauge, uncertainty bars, the corridor shading — comes from one of the formulas below. Nothing is a cosmetic number.

01 Vehicle motion — kinematic bicycle model

Every wheeled agent (ego included) integrates forward with:

\[ \dot{x} = v\cos\theta, \qquad \dot{y} = v\sin\theta, \qquad \dot{\theta} = \frac{v}{L}\tan\delta, \qquad \dot{v} = a \]

L = wheelbase, δ = steering angle (clamped), a = commanded acceleration. Integrated with a fixed timestep Δt.

Soft agents (pedestrian / animal / pushcart)

\[ \dot{x} = v\cos\theta, \qquad \dot{y} = v\sin\theta, \qquad \dot{\theta} = \omega, \qquad \dot v = a \]

A point-mass model — no wheelbase constraint, direct heading-rate control ω.

02 Longitudinal control — IDM-style car following

\[ a = a_{max}\left[1 - \left(\frac{v}{v_{target}}\right)^4 - \left(\frac{s^*(v)}{s}\right)^2\right], \qquad s^*(v) = s_0 + vT \]

s = gap to the leading agent, s₀ = minimum standstill gap, T = desired time headway.

03 Ripple propagation on the interaction graph

The interaction graph is rebuilt every tick: nodes are live agents, edge weight decays with distance:

\[ w_{ij} = e^{-d_{ij} / (0.5\, R)} \qquad \text{for } d_{ij} < R \]

A detected root event (magnitude \(m_0\), e.g. a hard brake or swerve) propagates hop by hop; the disturbance delivered to a neighbor is:

\[ m_{k+1} = m_k \cdot w_{ij} \cdot 0.85, \qquad \text{delivered after delay } \tau = r_j + \frac{d_{ij}}{25} \]

r_j = that agent's own reaction-time constant. Propagation stops once m falls below a minimum threshold or after 3 hops.

04 Intent estimation & behavior uncertainty

Each perceived agent carries a probability distribution over six maneuver hypotheses \(P = \{p_h\}\), updated from observed heading-rate, deceleration, and nearby ripple events. Behavior uncertainty combines the distribution's entropy with a live surprise score:

\[ H(P) = \frac{-\sum_h p_h \ln p_h}{\ln|\mathcal{H}|} \in [0,1] \] \[ \text{surprise}_t = 0.65\cdot\text{surprise}_{t-1} + 0.35\cdot \min\!\left(1,\ \frac{\lVert \mathbf{x}_t - \hat{\mathbf{x}}_t \rVert}{0.4 + 0.35v}\right) \] \[ U_{behavior} = 0.6\, H(P) + 0.4\,\min(1,\text{surprise}) \]

\(\hat{\mathbf{x}}_t\) is the naive constant-velocity extrapolation of the agent's previous observed state — sustained deviation from it is exactly what "behaving unexpectedly" means here.

05 Multi-cause uncertainty combination

\[ U_{total} = 0.35\,U_{behavior} + 0.20\,U_{perception} + 0.30\,U_{occlusion} + 0.15\,U_{environment} \] \[ U_{perception} = 1 - \text{confidence}, \qquad U_{occlusion} = \min\!\left(1, \frac{t_{unseen}}{2.0}\right), \qquad U_{environment} = \min\!\left(1, \frac{|w(s{+}3) - w(s{-}3)|}{2.5}\right) \]

This directly widens that agent's effective safety margin: \(m_{eff} = m_{base}\,(1 + U_{total})\).

06 Risk scoring & candidate cost

For every candidate maneuver, at every rolled-out future point of every perceived agent's every hypothesis:

\[ \text{risk} = \sum_{\text{agents}}\sum_{h}\sum_{t} p_h \cdot \text{severity}(d)^2 \cdot e^{-0.5t}, \qquad \text{severity}(d) = \max\!\left(0,\ \frac{1.5\,s_{safe} - d}{1.5\,s_{safe}}\right) \]
\[ \text{cost} = w_{risk}\cdot\text{risk} + w_{comfort}\cdot\text{comfort} + \text{progress} + w_{offroad}\cdot\text{offroad} + w_{occl}\cdot\text{occlusion} + \text{penalty}_{FSM} \]

progress = −2.0·(s_end − s_start) (a completed reward, so braking unnecessarily is never free). w_risk itself scales with the Risk Budget (§8).

07 Dynamic drivable corridor

At each forward station \(s\), the corridor bound narrows from the raw road half-width by every nearby obstacle and agent (padded by its own uncertainty):

\[ \text{left}(s) = \min\Big(\tfrac{w(s)}{2},\ \min_{i:\,|s_i-s|<4}\big(\text{lat}_i - (0.9 + 1.5\,U_i)\big)\Big), \quad \text{(symmetric for right)} \]

08 Traffic Stress Index & Risk Budget

\[ S = 100\big(0.30\,\rho + 0.25\,\phi + 0.25\,\omega + 0.20\,\kappa\big) \in [0,100] \]

ρ = nearby-agent density (saturating at 8), φ = active ripple-disturbance load, ω = occluded-detection fraction, κ = the planner's own last top risk score.

\[ B = \max\!\left(0,\ (100-S)^{1.15} / 100^{0.15}\right), \qquad w_{risk} = w_{base}\cdot\min\!\left(2.2,\ \sqrt{100 / \max(5,B)}\right) \]

The Behavior FSM's state is a direct, hysteresis-smoothed function of \(S\) (see the Explain page's stress table) — the state machine and the cost function are driven by the same number.

09 Safety Shield — independent verification

Deliberately simpler: no hypotheses, pure constant-velocity extrapolation of every perceived agent, checked against the planner's chosen path:

\[ \hat{\mathbf{x}}_{agent}(t) = \mathbf{x}_0 + v\,(\cos\theta,\sin\theta)\,t, \qquad \text{veto if } \min_t \lVert \hat{\mathbf{x}}_{agent}(t) - \mathbf{x}_{ego}(t)\rVert < s_{safe} + 0.7 \ \text{for } t<1.3\text{s} \]
All constants above (weights, thresholds, decay rates) are defined once, in code, in sim/planning/ and sim/safety_shield/ — this page mirrors them rather than restating a separate spec, so it can't drift out of sync with what actually runs.
